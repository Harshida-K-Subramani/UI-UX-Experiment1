# UI-UX-Experiment1

## Aim:
To study the fundamentals of UI and UX, understand their differences, relationship and various UI/UX design tools.
## Algorithm:
1. Open a UI/UX design tool and explore its features.
2. Study the basic concepts and principles of UI and UX.
3. Identify the differences between UI and UX using real-world examples.
4. Understand how UI and UX work together in a design.
5. Explore various UI/UX tools such as Figma, Canva, Adobe XD and Balsamiq.
6. Study the features and uses of each design tool.
7. Analyse how these tools help in creating user-friendly designs.

## Output:
1. Fundamentals of UI and UX


- UI (User Interface): It deals with the visual elements of an application, such as buttons, colours, icons, fonts and layouts.
- UX (User Experience): It focuses on the overall experience of users while using an application, including ease of use, navigation and satisfaction.


2. Difference Between UI and UX Using Real-World Case Studies
UI	UX

Focuses on appearance.	Focuses on user experience.
Includes buttons, colours and icons.	Includes navigation and usability.
Makes the application attractive.	Makes the application easy to use.

Example: In an online shopping application, product images and checkout buttons are UI, while searching for products and completing purchases easily are UX.


3. Relationship Between UI and UX in Design

UI and UX work together to create a successful application. UX focuses on planning the user journey, while UI focuses on designing the visual elements. Both are important for creating an attractive and user-friendly application.

4. Various UI/UX Design Tools
- Figma: Used for designing interfaces and creating prototypes.
- Canva: Used for creating graphics, logos and presentations.
- Adobe XD: Used for UI design and prototyping.
- Balsamiq: Used for creating wireframes.
- Sketch: Used for designing user interfaces.
These tools help designers create, test and improve digital products.


## Result:
The fundamentals of UI and UX, their differences, relationship in design and various UI/UX design tools were successfully studied.
